# CATMuS integration trial, 22 September 2026

Purpose: exercise the second reader and its preservation workflow on actual
F-eo5z imagery. The coordinator already knows the proposed identification;
Kraken receives only the image pixels and fixed model weights. This is tool
validation, not a new independent LLM reading or the planned comparative pilot.

## Recorded run

[Preserved raw HTR record](../fragments/F-eo5z/readings/catmus-2026-09-22.json)

- Fragment: [F-eo5z](https://fragmentarium.ms/overview/F-eo5z), first canvas,
  labelled `fol. [2]v-[1]r`, second column from the left.
- Native canvas: 8835 by 6796 pixels. Requested IIIF region:
  `2000,150,2000,6400`, output width 2000, rotation 0. The complete public IIIF
  request and image SHA-256 are in the saved record. No enlargement or other
  preprocessing was applied by the runner.
- Kraken 7.1.1, CATMuS Medieval release record 1.6.2, bundled baseline segmenter.
  Model hashes and the macOS ARM64/Python/package environment are recorded.
- Result: **62 detected segments**, with raw abbreviated text. This is not a count
  of verified physical lines. Visual inspection shows splitting at the top of
  the crop, interference from the photographed ruler, and damaged/folded text.
  The raw output retains obvious recognition errors.

## Failure observed and handled

The earlier tightly enlarged crop around the leprosy argument (3600 by 1600
pixels) yielded **zero detected lines** while Kraken itself exited successfully.
The adapter now retains the diagnostic output, exits with status 2, and refuses
to freeze that run as a reading. Its paired enlarged crop yielded 58 detections,
showing that a large detection count does not itself indicate good segmentation.
A wider archived crop also recognized text but split several lines badly.

Do not silently choose the result closest to the expected edition. Inspect the
input and line overlay, record new input geometry when changing crops, and retain
uncertainty. Native column context helped produce usable comparison material in
this trial, but it did not solve segmentation or transcription accuracy.

The existing manuscript report and identification have not been changed.
